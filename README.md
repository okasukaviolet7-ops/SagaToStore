# ASTRA: LEGENDS OF ETERNITY
An original browser-based anime fantasy card battle game. Built with HTML5, CSS3 and vanilla JavaScript.

## Run locally
Open `index.html` in a modern browser. For GitHub Pages, upload the complete folder contents to the repository root and enable Pages from the `main` branch / root folder.

## Files
- `index.html` — app structure and screens
- `style.css` — responsive visual design
- `cards.js` — 20 original character definitions
- `game.js` — navigation, collection, profile, storage and UI
- `summon.js` — gacha probabilities and duplicate conversion
- `deck.js` — saved deck management
- `battle.js` — turn-based battle and AI
- `audio.js` — generated sound effects using Web Audio
- `assets/cards/` — original vector character portraits

## Notes
All progress is stored in this browser's localStorage. Clearing browser site data will erase local saves. Audio begins only after user interaction. The character portraits are original vector illustrations included locally, so no external image hosting is required. Google Fonts are optional; system fallbacks are provided.
